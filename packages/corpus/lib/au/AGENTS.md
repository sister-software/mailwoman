# AGENTS.md — corpus sources for Australia

## Electing address data

Australian copyright requires human authorship of a compilation's expression (IceTV v Nine Network [2009] HCA 14; Telstra v Phone Directories [2010] FCAFC 149), and Australia has no database right.

Government address data is still Crown copyright under the Copyright Act 1968, Part VII, so a government file carries the Commonwealth's or a state's copyright whatever its factual content. G-NAF is elected on its own end-user license.

This repository has adopted no factual-data reading for Australia. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data, which those rules defer to.
