# AGENTS.md — corpus sources for Taiwan

## How this repository elects address data

This repository has adopted no factual-data reading for Taiwan. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

Taiwan's government data is elected on the Open Government Data License, version 1.0, where its publisher states it.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data, which those rules defer to.
