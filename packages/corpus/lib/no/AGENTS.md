# AGENTS.md — corpus sources for Norway

## How this repository elects address data

Norway applies Directive 96/9/EC through the EEA Agreement, implemented in its copyright act (åndsverkloven § 24 on catalogues and databases). An address register is a database under that right, so its rows are elected only on the publisher's grant.

This repository has adopted no factual-data reading for Norway. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data, which those rules defer to.
