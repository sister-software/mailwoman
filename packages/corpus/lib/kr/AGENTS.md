# AGENTS.md — corpus sources for South Korea

## How this repository elects address data

The Copyright Act of the Republic of Korea, Articles 93 to 98, gives a database producer exclusive rights over reproduction and distribution of all or a substantial part of a database for five years.

The road-name address database is such a database, so it is elected on the ministry's own statement on data.go.kr.

This repository has adopted no factual-data reading for South Korea. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data, which those rules defer to.
