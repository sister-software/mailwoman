# AGENTS.md — corpus sources for Singapore

## How this repository elects address data

Singapore grants copyright in a compilation only for human authorship in its selection or arrangement (Global Yellow Pages v Promedia Directories [2017] SGCA 28), and Singapore has no database right.

Government works hold Government copyright under the Copyright Act 2021, so a Singapore Land Authority file is elected on its stated license, the Singapore Open Data Licence.

This repository has adopted no factual-data reading for Singapore. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data. Those rules defer to it.
