# AGENTS.md — corpus sources for New Zealand

## How this repository elects address data

New Zealand has no database right. The Copyright Act 1994 counts a table or compilation as a literary work (section 2), so a compilation's copyright depends on its own originality rather than on the investment behind it.

Government address data is still Crown copyright under section 26 of that Act, so a Toitū Te Whenua LINZ file holds the Crown's copyright whatever its factual content. LINZ publishes the NZ Addresses layer (LINZ Data Service layer 123113) under Creative Commons Attribution 4.0 International, and `nz-property-building-1` is elected on that grant with LINZ's credit for an adapted work.

This repository has adopted no factual-data reading for New Zealand. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data. Those rules defer to it.
