# AGENTS.md — corpus sources for New Caledonia

## How this repository elects address data

New Caledonia is a French collectivity sui generis and an overseas country and territory of the EU, outside the Union itself. This repository has adopted no factual-data reading for New Caledonia. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

New Caledonia's public bodies publish on `data.gouv.nc`, the territory's open-data portal. A dataset record there that gives the body as publisher and states Licence Ouverte 2.0 is that body's grant. OPT-NC's agency list is elected on such a record. The service that serves the list states no license of its own.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data. Those rules defer to it.
