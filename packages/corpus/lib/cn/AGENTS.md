# AGENTS.md — corpus sources for China

## How this repository elects address data

This repository has adopted no factual-data reading for China. Its rows are elected only on the publisher's own grant, read as `../../AGENTS.md` "License election" describes.

The shared rules for reading a publisher's terms are in `packages/corpus/AGENTS.md` under "License election". This file states only the country's legal position on address data, which those rules defer to.
