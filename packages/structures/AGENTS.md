# AGENTS.md — `@mailwoman/structures`

Read the repository-root `AGENTS.md` first. This file covers the structure-source register: the building, landmark,
tree-height and basemap sources a published map layer reads, and the license decision behind each one.

## Layout

Each jurisdiction has a module at `lib/<cc>/sources.ts` exporting `<CC>_SOURCES` and `<CC>_LICENSES`. A source that
spans countries, such as OpenStreetMap or Overture, lives in `lib/international/sources.ts`. A state or city publisher
records its ISO 3166-2 code as `region`, and a city dataset also records `municipality`. `lib/register.ts` assembles
the modules, and `auditStructureRegister` checks ids, regions and every decision.

License decisions use the shape in `@mailwoman/core/license/decision`, which the corpus address-source register
also uses. The operations are `StructureOperation`: `fetch`, `convert`, `adapt`, `redistribute` and
`commercial-sublicense`. A published layer needs all five, because every viewer's browser downloads the adapted
geometry.

## How to elect a decision

The rules in `packages/corpus/AGENTS.md` under "License election" apply here. In particular, a grant permits only
what it states, and an omission is recorded as `unreviewed` rather than read as permission.

1. Retrieve the publisher's own terms, never a portal's or an aggregator's label for them. Read the dataset's own
   record. Two releases of one dataset can have separate records, as Hamburg's textured and untextured LoD3.0-HH do.
2. Save what was read under `data/licenses/<licenseID>.md`, with the URL and retrieval date at its head and a `Form`
   line stating whether the file holds the full text or excerpts. A file is never edited after retrieval. A new
   retrieval is a new file.
3. Record the decision with `retrievedCopy` pointing at that file, `electedBecause`, and one `because` per operation
   citing the clause that permits it. `permittedByGrant` in `lib/grants.ts` builds the five decisions when the grant
   permits all of them.
4. Record the credit the terms require as the source's `attribution`, verbatim where the publisher gives wording, and
   add a modification note where the terms require changes to be marked (DL-DE BY 2.0 §3, the PLATEAU site policy,
   CC BY 4.0 §3(a)(1)(B)).

A source the map draws while its decision is still `unchecked` still needs an `attribution`, because the credit is
owed whether or not the review is finished.

## Credits

`lib/basemaps.ts` maps each basemap and the hillshade to the register sources they read. `creditsFor` returns their
credits and throws when a listed source has no `attribution`. Earth's footer builds its basemap credits from it, so a
new basemap input joins `BASEMAP_INPUTS` and the register in the change that adds it to the build.

## PLATEAU tilesets

`data/plateau-tilesets.json` is generated by `node packages/structures/sdk/plateau/tilesets.run.ts` from PLATEAU
VIEW's catalog, and `npx oxfmt packages/structures/data/plateau-tilesets.json` sets it in the repository's format. Each
entry also records its geoid height from GSI's geoid service. Earth subtracts it to seat the ellipsoidal
PLATEAU heights on the map's ground. Each entry records its CKAN dataset's `license_title`, and `electedPlateauTilesets` keeps the ones
under the PLATEAU site policy. The `jp-plateau-site-policy` decision elects that policy. Regenerate the file rather than
editing it.

## Share-alike

OpenStreetMap, Overture and Daylight are ODbL, so a database built from them, including a published PMTiles archive,
is distributed under the ODbL. CC BY sources may be combined into it with their attribution. A CC BY-SA mesh is a
different share-alike and needs its own review before it is combined with an ODbL database.
