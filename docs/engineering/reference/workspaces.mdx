# Workspace catalog

Every workspace in the repository, grouped by the role it plays. The root `AGENTS.md` carries the
rules that apply across all of them, including the publish-set arithmetic and what a new workspace
has to join; this page answers which workspace a piece of work belongs in.

`readWorkspaceDirectories` in `@mailwoman/core/workspaces` reads the list this table describes, and
that reader is the one to trust when the two disagree.
