# 2026-09-08 — `v8-cjk-regs`: the re-sourced Korean register, Taiwan, and three noisy registries

Record of the run that re-sourced Korean from the ministry's own 주소DB, added Taiwan as a served locale of
`@mailwoman/neural-weights-cjk`, and trained on typed business addresses from three government registries aligned
against the LABEL corpora. Read against the pre-registration in
`corpus-python/src/mailwoman_train/configs/v8-cjk-regs.yaml`. Issue: #2204. The base it replaces is recorded in
`2026-09-06-v8-cjk-kr.md`.

## 1. The run

`v8-cjk-regs` seed 42, 8,000 steps, batch 256, bf16, cosine, from scratch: v8-cjk-kr's head, geometry, seed and
schedule, stopped at 8,000 because the last run's loss was flat from step 3,800 of 24,000. The corpus is the overlay
`v8-cjk-regs-2026-09-08` (vocabulary re-sealed over the union, 4,451 entries; 94,011 val rows):

## 3. One instrument defect

The probe's first KR `dependent_locality` read was 0.6288 while the model labeled the rows correctly. The board puts
two `dependent_locality` spans on 5,894 of its 20,000 rows (읍/면 plus the 리 below it, or the road form's
parenthetical 동), and the scorer built one gold surface per tag (the last span) against one predicted surface (the
first run), so those rows could never hit. `decode_all_spans` now scores every gold span against every predicted run
of its tag; the centroid key still reads the first span on both sides (bdb03334f, test pinned). The control's KR
numbers above are re-scored on the fixed scorer in the same session.

## 4. Served

`a876d99a1ce90faf1b3be5ab17ada97b`; vocabulary md5 `0fa613bcf93677f129e08f993bdf02c2` (4,451 entries, the repository's
tab-indented JSON form, byte-identical between the sealed corpus artifact and the served package). PyTorch↔ONNX
max_abs_diff 7.2e-6 over 256 rows (64 each from the JP kana, KR register, TW register and JP corporate-registry val
parts). The trainer's own `--parity-samples` path could not read the overlay's val parts locally: the MANIFEST names
the Modal volume's `/data/…` paths and the re-root only tries the overlay's own directory, so the parity read ran
through `verify_char_parity` over the same encoding from the local parts.

Package: `models/v8-cjk-regs-s42/served-package/` (model, vocabulary, receipt card). Card 0.0.3 and the Hugging Face
staging at `cjk/v0.0.3/` are the release step (§6 of #2204).
