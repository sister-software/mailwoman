# Switching from Nominatim

Nominatim is free and self-hosted. Running it also means running PostgreSQL, an `osm2pgsql` import that takes hours and tens of gigabytes, and a server that cannot ship inside an app or run in a browser. Mailwoman serves the same HTTP interface from a SQLite file. You can move your client without rewriting it and then remove the database stack.

## One command

```bash
npx @mailwoman/nominatim serve --port 8080
```

Point your client at it. With [geopy](https://geopy.readthedocs.io):

```python
from geopy.geocoders import Nominatim

geo = Nominatim(domain="localhost:8080", scheme="http")
geo.geocode("1600 Pennsylvania Ave NW, Washington DC", addressdetails=True)
geo.reverse((38.8977, -77.0365))
```

## Endpoint map

| Nominatim      | Mailwoman      | Notes                                                                                             |
| -------------- | -------------- | ------------------------------------------------------------------------------------------------- |
| `GET /search`  | `GET /search`  | free-text `q` and the structured fields                                                           |
| `GET /reverse` | `GET /reverse` | `lat` / `lon`, point-in-polygon over the same admin data                                          |
| `GET /lookup`  | `501`          | Nominatim looks up by OSM id; Mailwoman is WOF/Overture-keyed, so there are no OSM ids to look up |
| `GET /status`  | `GET /status`  | `{ status: 0, message: "OK" }`                                                                    |

Supported parameters are `q`, the structured set (`street`, `city`, `county`, `state`, `country`, `postalcode`), `countrycodes`, `limit`, `viewbox`, `bounded`, `addressdetails`, `accept-language`, and `format`. `format` accepts `jsonv2` (the default), `json`, or `geojson`. The `geojson` format returns a GeoJSON `FeatureCollection` with the coordinate in `geometry`, `boundingbox` in `bbox`, and the other fields in `properties`. Mailwoman ignores these less common Nominatim parameters: `extratags`, `namedetails`, `dedupe`, `polygon_text`/`_svg`/`_kml`, and `exclude_place_ids`.

## What's different

- **Richer results: annotations.** The API returns an `annotations` block. It contains coordinate formats (DMS, MGRS, geohash, Maidenhead, Mercator), the qibla bearing, sun times, the country flag, calling code, and currency, and the IANA timezone with its current (DST-correct) offset. Where the data bundles are present, it also contains the UN/LOCODE and EU NUTS codes. Nominatim returns none of these. [OpenCage](./how-mailwoman-compares.mdx) charges for the same block.
- **Ids.** Nominatim returns `osm_id` / `osm_type`. Mailwoman resolves over Who's On First and Overture, so it uses its own id scheme. Every result has a `place_id` that stays stable for that result.
- **Attribution.** The `licence` field lists the data sources (Who's On First, Overture, OpenAddresses, TIGER) rather than OSM.

## What's missing

- **Coordinate precision varies by coverage.** Where the address-point and street extracts have coverage, `/search` returns the rooftop or an interpolated point. For example, `1600 Pennsylvania Avenue NW` resolves to the building, with `addressdetails` down to `house_number` and `road`. Elsewhere, you get the admin centroid, which is the right place but not the exact building. The `addressdetails` always reflect what was parsed.
- **Bare ambiguous names can still collide.** The worldwide gazetteer ranks international cities by population, so `Vienna, Austria`, `Sydney`, and `Tirana, Albania` all resolve correctly. Coverage now includes many less-populous countries that used to return no result. When a US namesake outranks the place you meant, a bare query can still resolve to the American place. `countrycodes` selects the right one (`?q=Sydney&countrycodes=au`). Work is underway to have the coarse country router emit a country prior for those bare cases ([#822](https://github.com/sister-software/mailwoman/issues/822)). An exonym such as `Wien`/`Vienna` needs the model rather than the gazetteer.

See [how Mailwoman compares](./how-mailwoman-compares.mdx) for the capability matrix across Nominatim, Photon, OpenCage, Pelias, and libpostal. It includes two rows that the hosted services cannot satisfy.
