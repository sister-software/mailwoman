# Switching from Pelias

[Pelias](https://pelias.io) is a modular, self-hosted geocoder. Its importers for OSM, OpenAddresses, Who's On First, and other sources feed an Elasticsearch cluster. It is capable, and it takes a lot of work to operate: the cluster, the importers, gigabytes of data, and an analysis chain you tune by hand.

Mailwoman keeps what Pelias offers (self-hosting, open data, and hierarchy awareness) and removes the cluster. The hierarchy lives in SQLite, in a Who's On First `ancestors` table. A calibrated neural model does the work that Pelias's analysis chain did with rules.

## Mapping the move

Pelias has its own `/v1` response envelope, and Mailwoman does not ship a `/v1`-compatible package today. You migrate by mapping each capability to a Mailwoman package. Swapping the endpoint URL alone does not work:

| Pelias             | Mailwoman                                     |
| ------------------ | --------------------------------------------- |
| `/v1/search`       | `@mailwoman/nominatim` `/search` (structured) |
| `/v1/reverse`      | `@mailwoman/nominatim` `/reverse`             |
| `/v1/autocomplete` | `@mailwoman/photon` `/api`                    |
| structured parsing | `@mailwoman/libpostal` `/parse`               |

```bash
npx @mailwoman/nominatim serve   # structured search + reverse, with annotations
npx @mailwoman/photon serve      # autocomplete (GeoJSON)
```

## What's different

- **It needs neither Elasticsearch nor an import pipeline.** One SQLite gazetteer replaces the cluster and its imports.
- **A model replaces the analysis chain.** Parsing uses a calibrated neural tagger, so you get [a confidence you can route on](./confidence-calibration.mdx). You also get an OpenCage-style annotations block, which Pelias does not produce.

## What's missing

- **There is no `/v1` envelope yet.** If your client depends on Pelias's exact response, adapt it to the Nominatim or Photon shapes. A `/v1` adapter would be a reasonable contribution.
- **Coverage and ranking** still need long-term work. Pelias's mature importers still produce better results in some places.

See [how Mailwoman compares](./how-mailwoman-compares.mdx) for the capability matrix.
