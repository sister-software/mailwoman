# Switching from OpenCage

[OpenCage](https://opencagedata.com) is easy to use. It provides forward and reverse geocoding, and every result includes a detailed `annotations` block with timezone, coordinate formats, calling code, currency, flag, and more. It is also a hosted API, so you have to keep an API key secret and pay a per-request bill that grows with your usage.

Mailwoman's annotations layer provides the same block, self-hosted, **without an API key or a monthly fee**. Run `@mailwoman/nominatim`, and every result includes annotations with OpenCage's key names.

## One command

```bash
npx @mailwoman/nominatim serve --port 8080
```

```bash
curl "http://localhost:8080/search?q=Boston MA"
```

```json
{
	"lat": "42.332235",
	"lon": "-71.016397",
	"display_name": "Boston, MA",
	"annotations": {
		"DMS": { "lat": "42° 19′ 56.05″ N", "lng": "71° 0′ 59.03″ W" },
		"Maidenhead": "FN42lh",
		"Mercator": { "x": -7905509, "y": 5210877 },
		"geohash": "drt2zfr7n",
		"flag": "🇺🇸",
		"timezone": { "name": "America/New_York", "offset_sec": -14400 }
	}
}
```

The `annotations` keys match OpenCage's (`DMS`, `Maidenhead`, `Mercator`, `timezone.offset_sec`, …), so code that reads OpenCage annotations can read these.

## What's different

- **It has no key, fee, or rate limit.** It runs on your own machine from a SQLite file.
- The forward search uses the Nominatim response shape with the OpenCage `annotations` block added. The result is close to OpenCage's envelope but not byte-identical.

## What's missing

- **Annotation coverage is incomplete.** Shipped annotations are coordinate formats (DMS, geohash, Maidenhead, Mercator, qibla), flag, ISO, and the IANA timezone with a DST-correct offset. Calling code, currency, UN/LOCODE, and NUTS are planned. what3words is proprietary and out of scope.
- **Aggregated coverage.** OpenCage combines several backends, so it can resolve some places that Mailwoman cannot yet. Where that matters, combine OpenCage's multi-service guidance with Mailwoman as a [free first pass](../recipes/multi-service-geocoding.md).
