## Traps that cost time today

**Verify what a column MEANS before using it to validate another column.** Overture's `address_levels[2]` is
the administrative municipality, not the mailing city — `Greece → Rochester`, `Colonie → Albany`. Reading it
as the mailing city produced a confident, fully-measured, entirely wrong conclusion that NYC needed a licensed
USPS product. The numbers were all correct. The interpretation was not.

**A surprising result is not evidence the method was sound.** The same investigation used
`substr(postcode,1,3)` to select NYC and pulled in Gainesville TX and a row whose postcode was `111`.
`@mailwoman/codex/us/zipcode` ships `isZipCode` and `StateAbbreviationZipCodePrefixRecord`.

**Check for an existing home before reaching for a primitive.** Four times today: `simpleSHA3`
(`@mailwoman/core/crypto`), Kysely's `sql.ref`/`sql.table`, `codex/us/zipcode`, and `spliterator`. All four
were already dependencies of the file being edited. The failure mode is not ignorance of the rule — it is that
editing a line inside an existing function feels local even when it changes the input by two orders of
magnitude.

**`oxlint-disable-next-line` covers exactly one line**, and `prefer-spliterator` reports at the START of a
member-expression chain rather than at the `.split(` call. Prose goes above the comment, the comment
immediately above the chain. oxfmt can also insert a line between a disable and its target and silently
un-suppress it.

**`tryParsingJSON(x, undefined)` returns `null`, not `undefined`.** Anything typed `T | undefined` needs
`?? undefined`.

**`path-ts`'s `extname` is wrong on a non-literal `string`** — it returns type `""`, so
`extname(n) === ".jsonl"` is a hard TS2367. `basename`/`dirname` are fine.

**`spliterator` has no BOM option** and a BOM lands inside the first header name — one silently missing
column, not a parse error. `header` also defaults to `true` even in array mode, so headerless data needs
`header: false` or the first row is eaten.

**Do not run a sweeping subagent in the shared working tree.** One did today, on top of 45 uncommitted
operator files, and CI went fully red because 31 of its files imported a helper that existed only on disk. Use
`isolation: "worktree"`.
