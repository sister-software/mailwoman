# Choose a Mailwoman operation

Mailwoman separates reading an address, locating a place, comparing records, and adding derived fields. These operations return different evidence and have different local data requirements. The table describes published 11.0.0 interfaces checked on 10 November 2026. “Executed” means the stated path ran with published packages in a verification installation. A published interface without an executed data-backed call has an unknown result for that installation.

## What the autocomplete check established

The published CLI ran from an installed 11.0.0 project with this FST path relative to that project:

```sh
mailwoman autocomplete "san franc" --fst node_modules/@mailwoman/neural-weights-en-us/fst-en-us.bin --limit 2 --json
```

The JSON `entries` array contained a `locality` entry with `name: "San Francisco"` and `wofID: 85922583`, plus a `county` entry with the same name and `wofID: 102087579`. Both had `completionTokens: ["francisco"]`. The command exited 0. It didn't return coordinates or complete a street address. A different weights package or installation needs its own FST path check.

## Check the release and the installation separately

A package export shows that an interface is published. A bundle registry shows that data can be acquired. Neither establishes that the data is installed or that an operation has measured accuracy for your inputs. [Limits and release status](/product/limits-and-status) separates published, buildable, installed, and evaluated claims for 11.0.0. [Data and locales](/docs/reference/data-and-locales) lists the specific data roles and installation checks. Start with [one parsed address](/docs/start) to see a complete executed path.

The source surfaces checked for this page are the published [`mailwoman` exports](https://github.com/sister-software/mailwoman/blob/v11.0.0/packages/mailwoman/package.json), [autocomplete implementation](https://github.com/sister-software/mailwoman/blob/v11.0.0/packages/mailwoman/lib/autocomplete-core.ts), [reverse interface](https://github.com/sister-software/mailwoman/blob/v11.0.0/packages/resolver-wof-sqlite/lib/reverse.ts), [matcher exports](https://github.com/sister-software/mailwoman/blob/v11.0.0/packages/match/lib/index.ts), and [annotation exports](https://github.com/sister-software/mailwoman/blob/v11.0.0/packages/annotations/lib/index.ts). The linked guides record the completed calls and their exact inputs.
