# Add place-name autocomplete

Use the published finite-state transducer (FST) to suggest **place names** as someone types. The FST in `@mailwoman/neural-weights-en-us@11.0.0` runs without a geographic database. Each suggestion is a place name with its Who's On First ID. Coordinates, street addresses and delivery evidence come from other sources. This example serves a small JSON endpoint and sends a fixed sequence of input events through it.

## Prerequisites

- Node.js 24 LTS or later.
- An ECMAScript module project, with `"type": "module"` in its `package.json`.

Install the two packages the example uses:

```sh
npm install --save-exact @mailwoman/resolver-wof-sqlite@11.0.0 @mailwoman/neural-weights-en-us@11.0.0
```

Check that `node_modules/@mailwoman/neural-weights-en-us/fst-en-us.bin` exists in this project before starting the server. The path is relative to the project directory. The [data and locales reference](../reference/data-and-locales.mdx) distinguishes this place-name index from the geographic databases needed to resolve coordinates.

## Serve suggestions and check the request count

Save this code as `autocomplete.ts`. It loads the FST once, exposes `GET /suggest?q=...`, and runs a local client against seven input events. The client skips inputs shorter than three trimmed characters and suppresses an event when trimming leaves the same query as the previous request. The application chooses these rules.

```ts
import { createServer } from "node:http"
import { readFile } from "node:fs/promises"
import { autocomplete, deserializeFST } from "@mailwoman/resolver-wof-sqlite/fst"

interface Suggestion {
	name: string
	placetype: string
	wofID: number
}

const fst = deserializeFST(await readFile("node_modules/@mailwoman/neural-weights-en-us/fst-en-us.bin"))
let requests = 0

const server = createServer((request, response) => {
	const url = new URL(request.url ?? "/", "http://localhost")
	if (url.pathname !== "/suggest") {
		response.writeHead(404).end()
		return
	}

	requests++
	const query = url.searchParams.get("q")?.trim() ?? ""
	const entries: Suggestion[] =
		query.length < 3
			? []
			: autocomplete(fst, query, { maxSuggestions: 2, dedupeByName: true }).suggestions.map(
					({ name, placetype, wofID }) => ({ name, placetype, wofID })
				)
	response.writeHead(200, { "content-type": "application/json" }).end(JSON.stringify({ entries }))
})

await new Promise<void>((resolve) => server.listen(0, "127.0.0.1", resolve))
const address = server.address()
if (typeof address === "string" || address === null) throw new Error("Expected TCP address")

let lastQuery = ""
for (const input of ["s", "sa", "san", "san ", "san f", "san fr", "san franc"]) {
	const query = input.trim()
	if (query.length < 3) {
		console.log(`${JSON.stringify(input)}: skipped (short)`)
		continue
	}
	if (query === lastQuery) {
		console.log(`${JSON.stringify(input)}: skipped (unchanged)`)
		continue
	}

	lastQuery = query
	const response = await fetch(`http://127.0.0.1:${address.port}/suggest?q=${encodeURIComponent(query)}`)
	if (!response.ok) throw new Error(`HTTP ${response.status}`)
	const data = (await response.json()) as { entries: Suggestion[] }
	console.log(
		`${JSON.stringify(input)}: ${data.entries.map(({ name, placetype }) => `${name} (${placetype})`).join("; ")}`
	)
}
console.log(`HTTP requests: ${requests} of 7 input events`)
server.close()
```

Run `node autocomplete.ts`. The published 11.0.0 packages returned this complete output in the local check:

```text
"s": skipped (short)
"sa": skipped (short)
"san": San Antonio (locality); San Diego (locality)
"san ": skipped (unchanged)
"san f": San Francisco (locality); San Fernando (locality)
"san fr": San Francisco (locality); San Francisco Township (localadmin)
"san franc": San Francisco (locality); San Francisco Township (localadmin)
HTTP requests: 4 of 7 input events
```

Four of the seven input events made HTTP requests: `san`, `san f`, `san fr`, and `san franc`. The first two events were below this example's three-character rule, and `san ` trimmed to the already-requested `san`. The server also checks short queries, so a direct request gets the same length rule as the client. `dedupeByName: true` keeps one entry per displayed name. It changes the second result for `san franc` from the CLI's default. The CLI example on the [capabilities page](/product/capabilities#what-the-autocomplete-check-established) leaves deduplication off.

In an application, send the search field's current value to `/suggest` using the same trim, length, and unchanged-query checks. Render the returned `entries` as selectable place-name suggestions and keep each `wofID` as its place identifier. The example measures the request count for one fixed typing sequence. Measure response latency on your host and with your input mix before choosing a debounce delay.

The FST returns ranked gazetteer names and a `wofID` for each suggestion. See [geocoding](/docs/explanation/geocoding) for the separate lookup that supplies a coordinate, and [confidence and limits](/docs/explanation/confidence-and-limits) for evidence boundaries.
