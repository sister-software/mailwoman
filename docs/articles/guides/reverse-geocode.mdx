# Reverse-geocode a coordinate

Use this procedure to find the places that contain a coordinate, such as the neighborhood, city, region and country of a GPS reading. Mailwoman's reverse geocoder returns a Who's On First administrative hierarchy, from the smallest containing place up to the country. Street addresses and house numbers come from forward geocoding.

## Prerequisites

- Node.js 24 LTS or later.
- An ECMAScript module project, with `"type": "module"` in its `package.json`.

Install the published 11.0.0 packages:

```bash
npm install mailwoman@11.0.0 @mailwoman/neural@11.0.0 @mailwoman/neural-weights-en-us@11.0.0 @mailwoman/resolver-wof-sqlite@11.0.0
```

The reverse geocoder reads an admin gazetteer: a Who's On First SQLite database with a `place_bbox` spatial index. The 11.0.0 data bundles ship without one, and the `candidate.db` file from `mailwoman data pull candidate` lacks that index. Build the gazetteer from local clones of the Who's On First repositories, then add its search and spatial indexes:

```bash
npx mailwoman gazetteer build admin --data /path/to/whosonfirst-repos --out admin-global-priority.db
npx mailwoman gazetteer build fts admin-global-priority.db
```

The two commands above are checked against the published `--help` output only. The global gazetteer used for the output below came from an earlier build on the same host and occupies 7,316,430,848 bytes.

Point the reverse geocoder at the result:

```bash
export MAILWOMAN_WOF_ADMIN_DB="$PWD/admin-global-priority.db"
```

An optional polygon sidecar, read from `$MAILWOMAN_WOF_POLYGONS_DB`, holds place boundaries. With it, the geocoder tests whether the coordinate lies inside each place's boundary. Without it, the geocoder estimates containment from place centroids and bounding boxes. Step 2 shows the difference. The published CLI has no command that builds the sidecar.

The output below was captured with locally built admin and polygon databases. Place IDs and names in your output come from your own Who's On First build and can differ.

The output above is reformatted with one place per line. `hierarchy` runs from the smallest containing place to the country. Each entry's `id` is its Who's On First ID, and its `lat` and `lon` are that place's own representative point. The `lat` and `lon` at the top of the result echo your coordinate.

`containment: "approximate"` means no polygon sidecar was set. The finest place was chosen by its centroid, and `distanceKm` gives the distance from your coordinate to that centroid, 0.07 km here.

## 2. Use place boundaries

Set the polygon sidecar and repeat the command:

```bash
export MAILWOMAN_WOF_POLYGONS_DB="$PWD/wof-polygons.db"
npx mailwoman reverse 38.8977 -77.0365
```

The hierarchy is the same six places. The result now reads `containment: "polygon"`, and every `distanceKm` is `null`, because each place was confirmed by its boundary rather than estimated from its centroid.

`--format text` prints one place per line. For a coordinate in Arlington, Virginia, with and then without the sidecar:

```bash
npx mailwoman reverse 38.8816 -77.0910 --format text
```

```text
containment: polygon
  neighbourhood    Lyon Park [wof:420546549]
  locality         Arlington [wof:101729469]
  county           Arlington [wof:102085953]
  region           Virginia [wof:85688747]
  country          United States [wof:85633793]
```

```text
containment: approximate
  neighbourhood    Lyon Park [wof:420546549] (~0.3 km from centroid)
  locality         Arlington [wof:101729469]
  county           Arlington [wof:102085953]
  region           Virginia [wof:85688747]
  country          United States [wof:85633793]
```

Both runs returned the same places for this coordinate. The approximate method chooses the finest place by centroid distance, so close to a boundary it can choose the neighboring place. Neither tested coordinate showed that case. Use the sidecar when the finest place matters, and treat an `approximate` answer as an estimate.

## 3. Handle coordinates outside every place

A point in open ocean returns an empty hierarchy:

```bash
npx mailwoman reverse 35 -40 --format text
```

```text
containment: approximate
(no admin hierarchy — point may be in open ocean or outside the gazetteer coverage)
```

In JSON output, `hierarchy` is an empty array. The command still exits 0, so check the hierarchy's length rather than the exit status. The result reads `approximate` even with the sidecar set, because no boundary contained the point.

## 4. Reverse-geocode a list of points in a script

For a list of coordinates, such as a fleet's GPS readings, open the geocoder once and reuse it. Save this script as `reverse-points.ts`:

```ts
import { WOFReverseGeocoder } from "@mailwoman/resolver-wof-sqlite"

const geocoder = new WOFReverseGeocoder({
	adminDBPath: process.env.MAILWOMAN_WOF_ADMIN_DB,
	polygonDBPath: process.env.MAILWOMAN_WOF_POLYGONS_DB,
})

const points = [
	{ id: "truck-1", lat: 38.8977, lon: -77.0365 },
	{ id: "truck-2", lat: 38.8816, lon: -77.091 },
	{ id: "truck-3", lat: 48.8584, lon: 2.2945 },
	{ id: "ship-1", lat: 35, lon: -40 },
]

try {
	for (const point of points) {
		const result = geocoder.reverseGeocodeSync(point.lat, point.lon)
		const locality = result.hierarchy.find((place) => place.placetype === "locality")
		const country = result.hierarchy.find((place) => place.placetype === "country")
		console.log(
			`${point.id}: ${locality?.name ?? "-"}, ${country?.name ?? "-"} (${result.containment}, ${result.hierarchy.length} places)`
		)
	}
} finally {
	geocoder[Symbol.dispose]()
}
```

```bash
node reverse-points.ts
```

```text
truck-1: Washington, United States (polygon, 6 places)
truck-2: Arlington, United States (polygon, 5 places)
truck-3: Paris, France (polygon, 7 places)
ship-1: -, - (approximate, 0 places)
```

`reverseGeocodeSync` answers each point from the open database. `reverseGeocode` is its promise-returning form. Close the geocoder when the batch is done so its database handles are released. A point with an empty hierarchy, like `ship-1`, prints `-` for its locality and country. Record it as unplaced, with its own coordinate.
