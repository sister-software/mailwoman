# Why a geocode coordinate has a precision tier

Why can Mailwoman return a coordinate for a full street address without locating its building? The parser identifies text such as a street, house number, and locality. The geocoder searches geographic records for those components. It may find an address point, an estimated point on a street, or only a representative point for a postcode or place. `resolution_tier` states which kind of record supplied the selected coordinate.

## The resolver identifies places before selecting a point

A parser can label `New York` as a locality without a geographic database. A resolver asks the installed place index which locality records have that name. It can use a supplied country, postcode, parent place, or proximity preference to narrow and rank candidates. A name match can identify a city while still leaving the street and building unresolved. [The parsing explanation](./parsing.mdx) describes the earlier labeling decision.

The resolver attaches identities and alternatives to the parsed tree. The geocode extractor then selects one coordinate from the resolved evidence. A candidate's ranking score compares possible places for that answer. It doesn't measure distance from the actual destination. The [data and locales reference](../reference/data-and-locales.mdx) lists the published geographic bundles. A listed bundle doesn't establish that it is installed or that it contains a row for the input address.

## The selected record determines the tier

The result extractor prefers a matched address point. If no suitable point is present, it can use an interpolated house-number point, a street point, or a resolved postcode or administrative place. A matched venue can supply another point. An address with a parsed `house_number` can therefore return an `admin` or `postcode` coordinate when no finer record matches. The parsed text remains in the result; `resolution_tier` describes the coordinate.

An address point comes from a recorded row. Interpolation computes a position from a street range. A street or place point represents a larger area. The returned `coordinate_source` identifies a stamped address-point or interpolation row when the row records a source and release. The published landmark branch can stamp a venue source too. The field can be `null` when the selected tier or row supplies no stamp. `epistemic_status` states what kind of claim the selected evidence supports, independently of the tier. The [result schema](../reference/schema.mdx#geocode-result-and-provenance) defines these fields and their conditions.

The selected mechanism may report `uncertainty_m`, a radius in meters. A `null` value means it reported no radius. A small radius or decimal precision doesn't establish observed accuracy for the input. Accuracy requires a comparison with independently known positions for an identified data installation and input population.

## What a coordinate cannot establish

Reverse geocoding starts from a coordinate supplied by the caller. The published reverse resolver searches administrative bounding boxes and can check polygons when its polygon data is available. If no polygon confirms a place, it can return an approximate nearest-centroid result. The reported containment describes the relationship between the supplied point and the available administrative geometry. It cannot establish that the supplied point marks a building or a deliverable address. The [reverse-geocoding guide](../guides/reverse-geocode.mdx) shows the caller's task and the returned containment field.

The published 11.0.0 code and bundle registry establish these selection paths. This page has no complete forward or reverse run against an identified 11.0.0 geographic installation, so it makes no claim about the coordinate returned for a particular address. [Current product limits](/product/limits-and-status) distinguish available interfaces from release-matched geographic evidence. [Confidence and ambiguity](./confidence-and-limits.mdx) explains how a caller can use the tier, source, alternatives, and unresolved state together.
