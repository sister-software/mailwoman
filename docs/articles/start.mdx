# Install Mailwoman and inspect a first parse

You'll make a small TypeScript script that parses one address and prints each labeled part with its position in the text. The exercise installs the current published Mailwoman packages and takes about ten minutes, plus package download time.

## Prerequisites

- <NodeRequirement />.
- An empty project directory with room for the packages and the English model. This exercise reads no geocoding database.

## 1. Set up the project

Run this command in the empty project directory. It creates a `package.json` that marks the project as an ECMAScript module project. Node needs that setting to run the script's `import` statements and top-level `await`:

```sh
npm init -y --init-type=module
```

## 2. Install the package

```sh npm2yarn
npm install mailwoman
```

`mailwoman` installs the parser together with the classifier and the English model files. npm reports its download progress and dependency count for your environment. Check the installed Mailwoman version:

```sh
node -p "require('mailwoman/package.json').version"
```

```text
{{release.version}}
```

The address is lowercase, has no commas, and places the apartment before the street number. `parse` loads the English model on its first call and keeps it loaded for later calls. `decodeAsOutline` prints the returned tree one node per line and indents each child under its parent.

## 4. Run the script

Node runs the TypeScript file directly:

```sh
node parse.ts
```

```text
input: apt 4b 350 5th ave new york ny 10118
tree.raw: Apt 4B 350 5TH Ave New York NY 10118
locale: en-US
kind: structured_address
region [28, 30): "NY"
  locality [19, 27): "New York"
    street [11, 14): "5TH"
      unit [0, 6): "Apt 4B"
      house_number [7, 10): "350"
      street_suffix [15, 18): "Ave"
    postcode [31, 36): "10118"
```

The printed indentation shows the returned tree. Each node has a component tag, such as `street` or `postcode`, and a value. The `[start, end)` span selects text from `result.tree.raw`. For example, `result.tree.raw.slice(19, 27)` returns `"New York"`. Read spans against `tree.raw`, the case-adjusted text that the classifier returns with the tree. The script prints it on the `tree.raw:` line.

The `locale` and `kind` lines report the pipeline's decisions for this input. This script returns labeled address components. Forward geocoding reads a separate geographic data layer. [Geocode a file of addresses](./tutorials/geocode-a-file.mdx) installs one.

## What you have now

The `parse.ts` file runs a local parse and prints the case-adjusted text, classification, and component tree. You can replace the input string with another address and inspect its returned tags and spans with the same script.
