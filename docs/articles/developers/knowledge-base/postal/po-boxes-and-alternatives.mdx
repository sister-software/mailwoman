# PO boxes and other non-street addresses

## The question

`PO Box 1234, San Francisco, CA 94119` parses without errors and then geocodes to the middle of San
Francisco. Nothing failed, but the coordinate is not the box's location. This page explains what kind
of address this is, which other address shapes behave the same way, and what a geocoder should return
for them.

## The analog

A PO box is a shelf behind a counter. The postal service carries the item to the shelf and stops, and
the recipient comes to collect it. That is a complete delivery, and the address that describes it is a
complete address.

The address does not say where the recipient is. The person renting the box can live twenty miles away,
in a different town or county, and that separation can be the reason for renting one. A box is a delivery point
deliberately separated from a location. Asking where it is always returns the post office, the same
answer as for every other box at that office.

## The family

Several address shapes share that property, so treat them as one class.

**Post office boxes**, under whatever name the local service uses: `BP` in France, `Apartado` in
Spain, `GPO Box` and `Locked Bag` in Australia. The leader word and the number belong together, and the
whole phrase sits beside the town, never inside a street.

**General delivery**, called poste restante outside the US. The office holds mail for a recipient who
has no box and no fixed address there, and the recipient collects it in person. The address contains
only an office and a person.

**Private mailboxes** at a commercial mail receiving agency. These look like street addresses because
they are street addresses: the agency's. The US Postal Service requires the box to be marked with `PMB`
and a number, or alternatively `#` and a number, on its own line or appended to the street line
([Domestic Mail Manual 508](https://pe.usps.com/text/dmm300/508.htm)). Without that marking, a mail
drop looks the same as a suite in an office building, and it geocodes to a storefront that is a real
place but the wrong one.

**Rural route boxes**, where the address gives a route and a box along it instead of a street and a
number.

**Military addresses** routed through APO and FPO channels, where the code identifies an entry point
into a military postal network instead of a location on the ground.

## What Mailwoman does with them

The pipeline recognizes this class in two places. The kind classifier reports the input's shape before
the model runs, so a PO box is labeled as one. The parse then assigns the whole phrase to a single
`po_box` component that sits beside the locality instead of under the street.

There is no box resolver, and a resolver would not be useful, because every box at an office would
share one coordinate. A geocode of a box address therefore resolves the other parts of the string (the
town, the region, the postcode) and reports the administrative tier it used.
[Handle PO boxes and other edge kinds](../../how-to/handle-po-boxes-and-edge-kinds.mdx) has the
transcripts and the regional forms, and it covers intersections, bare postcodes and landmark queries
the same way.

## What it costs

Plan for three consequences.

A coordinate for a box address is the town's coordinate. It is the most the string can support, but it
is unusable for routing a driver. Check the resolution tier instead of trusting the coordinate.

Parsing identifies the shape of an address. It cannot tell you whether the address is real. A well-formed box address parses
whether or not the box is rented, and a private mailbox marked as a suite parses as a suite. Only a
postal authority's address file can confirm deliverability.
[Validate an address before you use it](../../how-to/validate-addresses.mdx) explains where parsing
stops and deliverability checks begin.

A person can also have several of these addresses at once: a street address where they live, a box
where they receive mail, and a mail drop for a business, with no component shared between them. Record
matching on address text alone treats them as three people. Matching on resolved components with an
explicit rule for box addresses avoids that
([Match messy records](../../how-to/match-messy-records.mdx)).
